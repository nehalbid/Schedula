# Schedula

Your Doctor Appointment App.

Schedula is a mobile application that helps you schedule and manage your doctor's appointments with ease.

## About the App

Schedula is designed to simplify the process of booking and keeping track of your medical appointments. Whether you need to find a new doctor, book a consultation, or manage your existing appointments, Schedula has you covered.

## Features

- **Find Doctors:** Browse a list of available doctors and view their details.
- **Book Appointments:** Easily book appointments with your chosen doctor.
- **Manage Appointments:** View your upcoming and past appointments.
- **Appointment Details:** Get detailed information about your appointments.
- **Cancel Appointments:** Cancel your appointments when needed.
- **Medical Records:** Keep track of your medical records.
- **Profile Management:** Manage your user profile and settings.
- **Authentication:** Secure login and registration.

## Getting Started

To get started with Schedula, you'll need to have Android Studio set up on your machine.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nehalbid/Schedula.git
   ```
2. **Open in Android Studio:**
   Open the cloned project in Android Studio.
3. **Set up Firebase:**
   - Create a new Firebase project.
   - Add an Android app to your Firebase project with the package name `app.schedula`.
   - Download the `google-services.json` file and place it in the `app/` directory (e.g., `Schedula/app/google-services.json`).
   - In the Firebase console, enable the **Authentication** and **Firestore** services.
4. **Build and run:**
   Build and run the app on an emulator or a physical device.

## Usage

Once the app is running, you can:

- Register for a new account or log in with your existing credentials.
- Browse the list of doctors and select one to view their profile.
- Book an appointment by selecting a date and time.
- View your upcoming appointments in the "Appointments" section.
- View your past appointments and medical records in the "Records" section.
- Manage your profile information in the "Profile" section.
